# PRD｜enterprise-ai-eval-harness 企业AI评测基座

## 1. 产品定位
面向 B 端 AI 交付 FDE、数据产品、RAG/Text2SQL/Agent 交付团队，提供**开箱即用的标准化评测工具**，
用于 POC 验收、版本回归、badcase 沉淀，解决 B 端 AI「缺少可量化验收标准、效果漂移无法追溯」的痛点。
本产品**不是学术评测框架**，以交付验收为第一目标，降低客户验收、迭代回归的人力成本。

## 2. 用户角色
- FDE 交付工程师：跑 POC 验收、给客户输出验收报告
- AI 产品：迭代 RAG/Text2SQL/Agent，对比版本效果
- 标注/测试：沉淀 badcase，回流优化模型与提示词
- 技术负责人：定期巡检模型效果基线

## 3. 用户故事
1. 作为交付 FDE，我需要批量跑一批用例，自动计算幻觉率、准确率、召回率，输出可交付客户的验收文档。
2. 作为产品，我需要对比 v0.1 / v0.2 版本效果差异，定位迭代带来的效果漂移。
3. 作为测试，我需要自动收集失败 case，打标签，导出给标注团队。
4. 作为使用者，我不需要复杂代码，通过可视化页面跑评测、看报表。

## 4. 核心功能清单
1. 评测集管理：导入/新建用例，字段 question、golden 答案、约束标签、风险标签、场景标签（rag/sql/agent）。
2. 评测任务管理：选择目标服务、选择 judge、限定场景。
3. 指标计算：业务准确率、拒答率、误拒率、漏拒率（合规风险）、超时率、异常率、答案召回率。
4. LLM-as-judge 自动打分（可选），固定 prompt 模板，未配置时走确定性打分。
5. 版本对比报表：多版本指标差异、变好/变差用例。
6. Badcase 库：自动归档失败/风险样本，支持导出 JSONL 给标注团队。
7. 报表导出：Markdown、CSV（可 Excel 打开），可直接作为客户验收材料。
8. Streamlit 可视化后台，本地无代码操作。

## 5. 非功能需求
1. 私有化部署，数据本地留存，不上传第三方平台。
2. 兼容 LiteLLM/OneAPI 模型网关，支持多种 LLM 后端（judge 可选）。
3. 单次评测集推荐量级：几十~上千条（POC 级别）。
4. 日志留存：评测任务记录、打分记录，可追溯。
5. 权限：单账号版本，适合内部小团队使用（暂不做多租户）。

## 6. 验收标准（v0.1，本仓库当前）
1. `docker compose up -d` 或 `make run` 可启动；`make demo` 可跑全链路。
2. 内置一份覆盖 RAG / Text2SQL / Agent 三类场景的样例评测集。
3. 完成一次评测，自动生成指标报表与 badcase 列表；`make test` 全绿。
4. 支持导出 Markdown / CSV / badcase JSONL。

## 7. 迭代路线
- v0.1：基础评测、单任务、报表导出、badcase 归档（当前）
- v0.2：批量版本对比报表、标签体系、评测集批量导入
- v0.3：Webhook 对接 CI，自动回归评测
- v0.4：社区共享评测集市场
